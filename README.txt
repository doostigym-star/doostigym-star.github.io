باشگاه دوستی — نسخه متصل به فضای ابری Supabase

این نسخه امکانات قبلی سایت، از جمله خروجی PDF بدهکارها و معرفی طراح را نگه می‌دارد و اطلاعات اعضا و اجاره را در Supabase ذخیره می‌کند.

مراحل راه‌اندازی (فقط یک‌بار):
1) فایل setup_cloud.sql را در Supabase > SQL Editor باز و Run کنید.
2) در Supabase > Authentication > Users یک کاربر مدیر با ایمیل و رمز قوی بسازید (Add user).
3) شناسه UUID کاربر ساخته‌شده را کپی کنید.
4) در SQL Editor این دستور را با UUID واقعی اجرا کنید:
   insert into public.gym_admins (user_id) values ('UUID-کاربر-مدیر');
5) در Authentication > Settings، ثبت‌نام عمومی (Allow new users to sign up) را غیرفعال کنید. کاربران مجاز را فقط از داشبورد به‌عنوان مدیر اضافه کنید و UUID آن‌ها را در gym_admins ثبت کنید.
6) فایل index.html را در مخزن GitHub Pages جایگزین نسخه قبلی کنید.
7) ابتدا روی همان کامپیوتری وارد شوید که اطلاعات قدیمی سایت در مرورگر آن ذخیره شده است. پس از ورود، اگر جدول ابری هنوز خالی باشد، اطلاعات محلی همان مرورگر به‌صورت اولیه به ابر منتقل می‌شود.
8) پس از پیام همگام‌سازی، از کامپیوترهای دیگر با همان ایمیل و رمز مدیر وارد شوید. اطلاعات ابری دریافت می‌شود و تغییرات دستگاه‌ها هر چند ثانیه همگام می‌شوند.

نکات امنیتی:
- کلید sb_publishable داخل index.html کلید عمومی و قابل استفاده در مرورگر است؛ امنیت داده‌ها با ورود کاربر و سیاست‌های RLS اعمال می‌شود.
- هرگز service_role یا secret key را در سایت یا GitHub قرار ندهید.
- قبل از جایگزین‌کردن سایت، از مخزن GitHub و اطلاعات فعلی نسخه پشتیبان بگیرید.
- اولین ورود را حتماً روی کامپیوتری انجام دهید که داده‌های قبلی اعضا در localStorage آن قرار دارد؛ مرورگرهای دیگر داده محلی جداگانه دارند.
- برای جلوگیری از تداخل ویرایش هم‌زمان، در لحظه یک مدیر اطلاعات را ویرایش کند؛ آخرین ذخیره، نسخه جاری خواهد بود.

آدرس پروژه و Publishable Key در فایل index.html تنظیم شده‌اند.
